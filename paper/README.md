# Paper evidence map

The JournalISI document is a formatting template, not an evidence source. Manuscript prose must only use verified outputs from this repository.

| Manuscript section | Repository evidence |
| --- | --- |
| Introduction | Research questions and externally managed literature review; no novelty claim from this repository |
| Methods | Architecture, provenance, canonical state, preprocessing audit, feature configuration, target construction, temporal splits, models, and metrics |
| Results | Generated dataset-quality tables, forecast metrics, occupancy ablation, integrity checks, and decision-support scenario outputs |
| Discussion | Technical limitations plus literature comparison performed separately |
| Conclusion | Only conclusions supported by held-out results and documented limitations |

Use `paper/figures/` and `paper/tables/` only for selected copies or links generated from `results/`. Do not type scientific values into manuscript files by hand.

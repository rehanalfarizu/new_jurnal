# Generated results

This directory contains outputs generated by versioned research code. Do not hand-edit result values.

- `metrics/`: model-level metric records and run manifests.
- `tables/`: dataset, quality, split, model, ablation, and integrity summaries.
- `figures/`: plots created from recorded input tables or predictions.

Every output must record the input file checksum, configuration, code commit, time boundaries, and run identifier. No result exists at the audit checkpoint.
